# Playscribe

PS5-first patch notes for iPhone Duo: follow your games, get told when an update lands on PS5, and read what changed as a game book.

| Path | What |
|---|---|
| `ios/` | SwiftUI app (Xcode) |
| `backend/` | Data service: source polling, review queue, APNs push, API |
| `docs/` | Contracts shared by the app and the backend |
| `.github/workflows/` | CI and release |
