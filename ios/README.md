# Playscribe for iPhone

SwiftUI, iOS 27.1 (the release with the iPhone Duo APIs). The project is generated by XcodeGen from
`project.yml`; run `xcodegen generate` first. See `../CLAUDE.md` for the rules and QA routes.

| Folder | What |
|---|---|
| `Playscribe/Model` | PS5 data contract (`PatchData.swift`), catalogue and fixtures, the shared `AppModel` |
| `Playscribe/Services` | Notifications (local now, APNs-ready) and the static feed client |
| `Playscribe/UI` | Screens. `Duo.swift` reads the pose from reserved regions; `RootView.swift` holds the tabs, split view and tabletop rail |
| `Playscribe/Resources` | Artwork, bundled catalogue, Dawnwalker 1.1 notes, the IGDB PS5 index |
| `PlayscribeTests` | Model tests, named after the acceptance IDs |
| `tools/` | Fixture builder and QA scripts |
