# Xcode's MCP server, headless

Agents on the Mac can build, run tests, render previews and drive a simulator through Xcode's MCP tools without
opening the Xcode UI. Verified 2026-11-11 on the Mac tester (no sudo needed once permission shows `enabled`).

## Start it (no sudo)

```sh
xcrun mcp-server status                      # want: Permission: enabled
xcrun mcp-server open /abs/path/to/ios/Playscribe.xcodeproj   # launches the server if needed, opens the project
xcrun mcp-server status                      # want: mcp-server: running, the project under "Open workspaces"
xcrun mcp-server stop                        # when finished
```

One-time, by a person with the Mac (needs sudo and Xcode > Settings > Intelligence > External Agent Access = Always;
agents never run these): `sudo xcrun mcp-server enable`. Folder and agent approvals (`allow-folder`, `approve`) also need sudo.

## Use it from an agent

`xcrun mcpbridge` is a stdio MCP server (JSON-RPC 2.0 on stdin/stdout), so any MCP client can launch it as
`xcrun mcpbridge`. Useful tools for this repo:

- `XcodeListWorkspaces`, `XcodeListSchemes`, `XcodeSwitchScheme`, `XcodeListRunDestinations`, `XcodeSwitchRunDestination`
- `BuildProject`, `GetBuildLog`, `XcodeRefreshCodeIssuesInFile`
- `GetTestList`, `RunAllTests`, `RunSomeTests` (scheme `PlayscribeUI` for UI tests)
- `RenderPreview`, `RunProject`, `StopProject`, `GetConsoleOutput`
- `DeviceInteraction*` (tap, swipe, type on a simulator)

Rules that still apply: the project is generated by XcodeGen, so run `cd ios && xcodegen generate` first; do not edit the
`.xcodeproj`. Stamp-SHA and QA routes in CLAUDE.md work unchanged on the built app.
