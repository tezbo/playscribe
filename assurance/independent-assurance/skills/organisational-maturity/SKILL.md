# Organisational maturity assessment

Load `assurance-charter` first; use the dimensions, levels and cap rule in `references/rating-scales.md`.

1. **Inputs**: the latest baseline, weekly working papers since the last maturity assessment, open findings, and a
   fresh evidence sample for each dimension (at least three cited items per dimension).
2. **Score each dimension 1 to 5** against the level descriptions, quoting the evidence that places it there and
   the evidence that keeps it from the next level.
3. **Apply caps** from open critical and major findings. List critical findings above the table.
4. **Trend**: compare with the previous assessment per dimension; a rise needs new evidence, not fewer findings.
5. **Sponsor-intervention index** for the period (count, ratio, three cited examples).
6. **Skills development**: new or changed skills and learnings in the period, and whether they changed behaviour
   (find a later instance of the skill being used unprompted). A skill that exists but is never used does not raise
   maturity.
7. **Agent Resources (conflict)**: the `independent-second-marker` agent re-scores Organisational learning and the
   skills part of the assessment; report both.

Output: `60-maturity/MM-<YYYY-MM>.md`. Never publish a single overall number without the lowest dimension beside it.
